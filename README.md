# 营养智链 —— 外卖个性化营养管理平台（前端）

> 三角色（用户 / 商家 / 营养师）协同的外卖营养管理 Web 前端，原生 HTML/CSS/JavaScript 单页应用，可由 Spring Boot 后端同源托管，也可独立静态运行。

## 运行方式

### 方式一：由后端同源托管（推荐，完整能力）
前端已内置到后端 `src/main/resources/static/`，启动后端后直接访问，识别请求走同源接口、无跨域、密钥不出后端：

```bash
cd ../backend
mvn spring-boot:run -Dspring-boot.run.profiles=local
# 打开 http://localhost:8080/
```

### 方式二：独立静态运行
```bash
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```
无后端时，订单文本解析与营养估算自动降级为本地成分库与规则解析，使用流程不中断。

### 方式三：单文件版
双击 `single.html`（CSS/JS/数据全内联，零依赖、可离线）。

## 功能清单（共 16 个页面）

### 用户端（8 页）
1. **总览/今日**：三餐时间线（早/午/晚/加餐）、热量与宏量营养素环形图、近 7 天趋势、糖摄入监控、协同动态
2. **订单导入**：订单截图/文本 → 智能结构化 → 候选逐项确认 → 保存，支持失败降级手动校正
3. **餐食拍照**：照片上传 → 菜品智能识别候选（菜名/置信度/参考热量）→ 份量校正 → 营养分析 → 保存
4. **饮品配置**：品牌/SKU、杯型、糖度、冰量、小料 → 证据门控营养计算、透明杯比例缩放、未知项不按 0 计
5. **记录与趋势**：日/周/月与三餐时段筛选、修改/删除/补录、来源查看、JSON 导出
6. **目标与设置**：个人画像、每日营养目标、隐私授权、本地数据管理
7. **协同社区**：记录即帖子、三方角色同帖互动、营养纠错可追溯、话题、搜索、收藏、举报
8. **项目展示**：命题背景、技术链路、三方协同闭环图

### 商家端（4 页）
商家工作台、数据分析（订单趋势/菜品点击/偏好分布）、菜品管理（营养资料与上下架）、社区运营。

### 营养师端（4 页）
复核工作台、用户管理（营养档案与达标率）、知识发布、数据统计。

## 技术栈

- 原生 HTML5 / CSS3 / JavaScript（ES6+），无框架、无构建工具
- Hash Router 单页路由，天然适配子路径部署
- 纯 SVG 数据可视化（环形、折线、柱状、饼图、协同流程图），零图表库依赖
- CSS Variables + Flexbox + Grid，玻璃态导航与微动效，响应式 1440 / 768 / 390
- localStorage 本地持久化（画像、记录、当前角色）
- 线性图标（Lucide，ISC License）

## 智能识别链路

- 前端统一调用同源接口 `POST /api/recognize/chat`（OpenAI 兼容消息结构，支持多模态图片），由后端 `SmartRecognizeService` 注入密钥并转发，承担菜品识别、订单结构化、营养估算三类任务。
- 前端代码**不含任何真实密钥**；启动时通过 `GET /api/recognize/health` 探测后端是否在线。
- 后端不可达时自动降级：营养估算使用内置成分表（FOOD_TABLE），订单解析使用本地规则，保证界面流程完整可演示。

## 目录结构

```
frontend/
├── index.html               # 应用壳层（导航/角色切换/出口）
├── single.html              # 零依赖单文件版
├── css/style.css            # 全部样式与响应式、动效
├── js/
│   ├── app.js               # 路由、全局状态、localStorage、角色导航
│   ├── data.js              # 基础数据（饮品库、三餐历史、协同事件、社区内容）
│   ├── recognize.js         # 统一智能识别客户端（同源调用 + 本地兜底）
│   ├── engine.js            # 证据门控饮品营养引擎（前端实现）
│   ├── components.js        # 通用组件与 SVG 图表
│   └── pages/               # 16 个页面模块
└── assets/                  # Logo 等静态资源
```
